# Megabonk (Manual) Setup Guide

## Required Software

- Archipelago 0.6.8 or newer
- Megabonk. A save with most characters, weapons, tomes and maps already unlocked works best, and the Toggler shop upgrade makes the rules easy to keep.

## Installation Procedures

1. Open the Archipelago Launcher and click "Install APWorld".
2. Pick `manual_megabonk_bryarpatch36.apworld`, then restart the Launcher.

## Joining a MultiWorld Game

1. In the Launcher, open "Manual Client".
2. Enter the game ID `Manual_Megabonk_bryarpatch36`, the server address, and your slot name.
3. Items you receive appear in the client. Before a run, switch off in the game's Toggler every weapon and tome you have not been sent.
4. Click a check in the "Manual" tab when you have done it in game.

## Game Troubleshooting

If "Manual Client" is missing from the Launcher, the apworld is not installed: check that `manual_megabonk_bryarpatch36.apworld` is in the `custom_worlds` folder of your Archipelago install.
